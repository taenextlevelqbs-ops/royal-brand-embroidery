# Royal Brand Embroidery — Business Website

A responsive website project for an embroidery and apparel business.

## Project summary
A Next.js-based web presence designed to showcase a business and its services. This repository is part of a larger portfolio of business website and application projects.

## Technology
- Next.js and React
- TypeScript
- Responsive web layout

## Run locally
```bash
npm ci
npm run dev
```
